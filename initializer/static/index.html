GitHub 必需

用于创建专用仓库、保存加密凭据、启动与停止预览。

已登录，接下来需要安装 GitHub App。只选择本项目需要的仓库。如果 GitHub 要求选择仓库却没有可选项，请先联系维护者，不要为了继续而改选“所有仓库”。

向导需要哪些 GitHub 权限？

读取模板内容、创建专用仓库、写入这个仓库的 Actions Secrets，以及启动和停止预览工作流。我们不申请修改工作流或删除整个仓库的权限。仅支持个人 GitHub 账号；不会自动放宽你组织的安全策略。

临时地址由 trycloudflare 提供，停止后失效。适合短期体验，偶尔可能不稳定；下次启动要更新 ChatGPT 连接。

临时地址有什么限制？

不支持 SSE，最多 200 个在途请求，也没有可用性保证。本项目使用 JSON 工具响应；通过检测不代表所有 ChatGPT 账号都兼容。

Cloudflare 可选

推荐给已经拥有可用域名、希望地址更稳定的用户。

仅有账号还不够：域名需要在你的 Cloudflare 账号中处于“已激活”状态。我们不提供平台域名。

将自动创建一个独立子域名，不覆盖现有 DNS 记录。

还没有可用域名

注册 Cloudflare 账号不会自动获得域名。域名接入与生效可能需要等待，你可以先保留 GitHub 设置，使用临时地址。

Cloudflare 授权与费用说明

需要查看域名、管理 Tunnel 和 DNS。Cloudflare 授权可能覆盖你选择的账号，不等于只允许修改这一条记录；向导只使用本次资源。账号管理权限留在初始化服务端，电脑只获得这条 Tunnel 的运行凭据。域名注册与平台用量可能另有费用。
